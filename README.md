# hoang-android-research

GitHub describes this repository as automatically exported from
`code.google.com/p/hoang-android-research`. The reviewed default `master` branch
contains no tracked source files. The separate `wiki` branch contains only
`ProjectHome.md`, a one-line project description. The official Google Code source
archive endpoint returned HTTP 403 during recovery inspection. This is a recovery
placeholder, not a runnable app.

Development plan:

1. Find the original exported source archive or a historical branch and verify its
   origin and license before adding it to this repository.
2. Inventory recovered modules, entry points, SDK/Java versions and external service
   requirements. Isolate tutorial samples from active applications.
3. Build the recovered code in a documented environment, add a smoke test through
   the actual application entry point, then prioritize concrete defects.

The current work documents the missing source and provenance. No source recovery,
Android build or functional change is claimed.

Reference: [Google Code Archive](https://code.google.com/archive/).
